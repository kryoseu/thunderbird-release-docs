# Reports

Reports generated from release data. They're rebuilt daily by the site's
[publish-site workflow](https://github.com/thunderbird/thunderbird-release-docs/blob/main/.github/workflows/publish-site.yml),
so they aren't committed to this repository.

- [Releases shipped on schedule](on-schedule.html) — how often desktop releases
  ship on the day the release calendar scheduled them, by channel. Generated by
  `tb-release on-schedule` from
  [thunderbird-release-tools](https://github.com/thunderbird/thunderbird-release-tools/tree/main/reports/on-schedule).
